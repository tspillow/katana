Katana Linux

## What am i looking at?
Katana Linux is an arch-based Linux distribution that adds a declarative system and more.

### Features
- Declarative configuration:
you can use a reproducible and unique ecosystem editing '/katana/declare/config.lua'.
add packages, enable services and more!
- Performance-optimized:
we use ananicy-cpp, a background service that dynamically adjusts resource usage between
different applications to reduce latency.


Katana has a good set of toolkits and quality of life features and custom scripts:

* kat
-- The official command toolkit for Katana.
it let's you rebuild your config, reset it to stock, update both AUR and pacman + system packages and more
to be planned.
* katcfg
-- this script literally takes you to your katana config
without typing 'nano /katana/declare/config.lua'! Useful for lazy people.
